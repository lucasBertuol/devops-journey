# DevOps journey
## Who am I
I am a developer with some experience on linux systems and a no-code automation background.

## My goal
My goal is to become a job-ready DevOps engineer by November 2027.

## Purpose of this repository
The purpose of this repo is to serve as my public learning journey into the DevOps world, where others can see what I did, learn from my successes and failures, and join me in creating a better IT workplace with DevOps. 

## How I will measure progress
I will certify my mastery on the main DevOps concepts and skills through open-source projects, tests and exercises that use techniques such as active recall and spaced retrieval (with flashcards), and certifications (like the CLF-C02 and SAA-C03). 

## What this repository contains
This repository will hold my weekly reflections, projects related to DevOps and some notes occasionaly.
